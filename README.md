# MAAAX Style Hub

Yes. Based on the reference, the client wants a premium fashion wholesaler/catalog + branch-based ordering website for MAAAX WHOLESALER. The strongest parts of the reference are the black/ivory/gold visual system, large fashion hero, clean category grid, product-detail layout, branch availability flow, and simple order confirmation.

For Lovable, I’d make the prompt more detailed than the screenshot so it creates a complete multipage website, not just five copied screens. One important change: instead of telling Lovable to scrape Pinterest images—which can create copyright/licensing issues—tell it to use high-quality fashion-editorial placeholder images from royalty-free sources or image URLs you provide later, with every major image unique.
